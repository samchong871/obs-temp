Request to install Obsidian for preparing software engineering documentation and technical note-taking. It uses standard markdown format which can be easily incorporated into developer documentation and Confluence. Like other md files, they can be version controlled, e.g. via Git. The portable format allows a consistent set of technical notes across corporate and off-net development environments (OneNote notebooks on OneDrive cannot be accessed on off-net machines) supporting onboarding, troubleshooting and knowledge sharing.
